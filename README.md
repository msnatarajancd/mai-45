# ReadyRelief — Protect. Respond. Recover.

Mastering Agentic AI Group Project

## Project Overview

ReadyRelief is an AI-assisted disaster preparedness,
emergency assistance, and recovery planning prototype.

## Modules

- M1: Application and Integration
- M2: Intelligent Guardian
- M3: Official Knowledge and RAG
- M4: Emergency Assistance and Safety
- M5: Recovery Copilot

## Technology

Python, Streamlit, Pydantic, SQLite,
Nebius Token Factory, and pytest.

## Safety

Educational prototype only.
Not an operational emergency service.
Does not dispatch emergency responders.
